# Frontend UI 스킬

상위 `AGENTS.md`를 따른다. 아래 스킬은 이 프로젝트의 프론트 UI 검토·수정에만 적용한다.

- 배치·반응형·줄바꿈·잘림·안전 영역 작업: `../.codex/skills/better-layout/SKILL.md`.
- 터치 영역·키보드·포커스·모달·접근성 작업: `../.codex/skills/better-accessibility/SKILL.md`.
- 모바일 UI 전반 검토에는 두 스킬을 사용한다. API 호출 로직·빌드 설정만 바꾸는 작업에는 불필요하게 로드하지 않는다.
- 사용할 스킬 본문과 해당 작업에 필요한 참조 문서를 읽는다. 스킬이 언급하는 다른 미설치 스킬을 자동 설치하거나 읽었다고 가정하지 않는다.
- 기존 테마·색상·폰트 토큰, 전역 focus-visible·reduced-motion 처리를 우선 재사용한다. 스킬 예시를 이유로 전역 스타일을 중복 추가하거나 디자인을 전면 교체하지 않는다.
- 사용자 요청 범위 내에서만 수정한다. 데모 UI는 명시적 요청 없이는 변경하지 않는다. 검토 요청은 코드 수정 권한이 아니다.
- 모바일 검증은 320·375·390·430px와 데스크톱 회귀를 기준으로 가로 넘침·긴 한국어 제목·터치 영역·고정 요소 가림을 확인한다. 화면 확대·키보드·스크린리더·실기기 검증은 수행한 범위를 구분하고, 못 한 검증은 명시한다.

스킬 원본: https://github.com/jakubkrehel/skills 의 `skills/better-layout`, `skills/better-accessibility` (2026-09-14 설치). 각 폴더의 참조 문서와 `agents/openai.yaml`을 함께 유지한다. 앱 런타임 의존성이 아니며 npm 설치나 OCI 설정은 필요 없다.
